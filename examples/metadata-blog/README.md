# Metadata Blog Example

This example combines metadata cascade, canonical links, Open Graph metadata,
JSON-LD, sitemap output, robots output, and a generated Open Graph image.

The root layout supplies the site title format and organization data. The post
adds article data and points to `/og/secure-routing/image.svg` for its Open Graph
image.

Run the example with:

```sh
pnpm build
pnpm start
```
